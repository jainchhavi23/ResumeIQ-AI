# ResumeIQ AI

An AI-powered resume analysis web application that helps users evaluate their resumes, compare them with job descriptions, and receive personalized suggestions for improvement.

## 🚀 Project Overview

ResumeIQ AI is designed to help students, freshers, and job seekers understand how well their resumes match a specific job role.

Users can upload their resume in PDF format and paste a job description. The application extracts information from the resume, identifies relevant skills, compares the resume with job requirements, calculates an estimated resume readiness score and job match score, and provides AI-powered feedback.

> **Note:** The scores generated by ResumeIQ AI are estimates created using the application's own analysis rules. They are not official scores from any company's Applicant Tracking System (ATS).

## 💻 Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ResumeIQ-AI.git
```

### 2. Open the project folder

```bash
cd ResumeIQ-AI
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```bash
.venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```bash
.venv\Scripts\activate
```

**Git Bash:**

```bash
source .venv/Scripts/activate
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open the application in your browser:

```text
http://127.0.0.1:5000/
```

## 🔐 Environment Variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
SECRET_KEY=your_secret_key
```

Do not upload the `.env` file to GitHub.
